# sheng iPadOS 27 research

This experimental branch records the 24A446 sheng bring-up and preserves the
working iPadOS 17 reference. See the [research log and tools](../../research/sheng-ipados27/README.md).

The source kernel is based on public XNU 12377.121.6 with the branch's Darwin
26 interface additions. No iPadOS 27 hardware boot or GPU success is claimed.
Source/input preparation and small host transport tests are recorded separately
from native kernel, GPU, firmware and device checkpoints.
