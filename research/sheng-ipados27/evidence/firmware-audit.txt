Mac policy-generation draft and exact hash semantics
Script:D:\iOS6sp\iPadOS27\scripts\firmware_agent_policy27.py
It is parameterized by resolved --tree, original --profile and two AEA-decrypted --os-dmg/--systemos-dmg inputs.
It automatically runs kits/VerifiedRoot/tests/check.py to generate/preserve one owner key, build the real C/OpenSSL provider and execute upstream signature/tamper/block-refusal checks.
There is no prerequisite named build-verified-root-host.py; the upstream kit's tests/check.py is the actual host builder.
It then attaches each input with hdiutil -nomount -readonly, selects the physical GUID whole image rather than a synthesized APFS whole container, verifies DiskImage/readonly/size and the actual APFS UUID association, calls manifest.make, opens the real C RSA view, and verifies every4096-byte raw media block.
Only after both complete digest checks and C block verification does it emit verification.json with real_c_signature_and_block_verification=true.
Both policies must share the same395-byte owner anchor; private keys must never be published in artifacts.
The source profile root pins are SHA256 of the complete virtual raw disk byte stream, not AEA archive bytes and not UDIF file bytes. This is confirmed by userdata.py disk_blocks()->raw device hashing and the root adapter's policy checks; the audit has not downloaded and independently hashed these two large raw disks yet.

Avoiding a10GB Actions artifact
Windows can download/decrypt/assemble locally using the native tool.
Mac Actions can fetch the same Apple members independently, create policies/kernel/Data seed, and return only the much smaller policy tables and build products.
The local root assembler must reproduce the exact raw profile hashes and policy windows.
Check real free space first: AEA input and decrypted UDIF coexist during decryption. Remove only each job's own encrypted temporary input after successful verified decryption if necessary; never remove existing17 assets.
No modified or synthetic verification JSON, skipped root blocks, renamed17 kernel, or macOS image can substitute for these actual27 inputs.
