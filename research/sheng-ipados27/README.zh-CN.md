# sheng 的 iPadOS 27 研究支线

目标固定为小米平板 6S Pro（sheng）的 **iPadOS 27.0.1 / 24A446**。
首次实机候选包含匹配的 GPU／Metal 和新建持久化 Data；17 成功案例保留在电脑端。

**目前尚未验证这台设备启动 27、27 的 GPU 或持久化 Data，也未生成完整可刷包。**

该分支使用公开 XNU 12377.121.6／Darwin 25.5，加上项目的 Darwin 26 接口适配运行
27 用户态；它不是 Apple 尚未公开的原生 Darwin 26 源码。选择 27 的原因是官方实验
分支已有对应的 GPU、显示、HID 绑定，26.5.2 缺少同等完整配方。

已经实际验证：

- 17 能进入可触摸的主屏幕，中文和深色模式跨相同镜像重启保留
- 27 的 Apple 恢复包身份、原始小部件和解压 kernelcache 的固定哈希
- Windows 端解密的 27 OS 和 SystemOS raw APFS 均与官方配置哈希一致
- macOS 端对两卷完成真实 C/RSA 认证和全部 4K 块验证
- Windows 已生成 15,349,546,184 字节的全分区 RAW/FILL 稀疏镜像，并回读核验两卷和两个表对象；未刷写设备，尚待最终 boot 策略绑定
- 新 SoC 补丁在受影响 Apple 文件上的顺序适用性、第一阶段云端源码／输入准备
- userdata 组包器的小型真实 RSA、v2 布局、全零尾部及篡改／截断负控

尚待完成：新 Data、完整内核／GPU／新版固件构建、最终 boot 策略绑定与设备验证。
17 的 GPU 加速和实际在线 CPU 核数同样未测，不把已有桌面当作 GPU 成功证据。
